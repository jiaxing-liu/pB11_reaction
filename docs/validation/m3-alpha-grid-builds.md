# Alpha-grid compiler validation

Checked 2026-09-14. This checkpoint verifies the numerical API and bindings,
not a complete pB spectrum or an EXL/BALDUR production run.

| Build | Directory | CTest |
|---|---|---|
| GNU C++/gfortran | /tmp/m3-grid-gnu | 23/23 |
| GNU C++/ifx default REAL | /tmp/m3-ifx-r4 | 23/23 |
| GNU C++/ifx -r8 | /tmp/m3-ifx-r8 | 23/23 |
| GNU C++, PB11_BUILD_FORTRAN=OFF | /tmp/m3-no-fortran | 15/15 |

Intel builds use Release and `-check all -traceback`, with `-r8` added only
for the second ABI check. GNU's CMake build type and extra Fortran flags are
empty in this checkpoint; no-Fortran is Release. All C interfaces use double,
and the wrappers use explicit c_double and c_int independent of default REAL.
The new structure contains eleven doubles and two C integers (96 bytes on
the checked platform).

Reproduce with CMake configure/build/ctest, for example:

```
cmake -S . -B /tmp/m3-grid-gnu -DPB11_BUILD_FORTRAN=ON
cmake --build /tmp/m3-grid-gnu -j4
ctest --test-dir /tmp/m3-grid-gnu --output-on-failure
```

For Intel source `/opt/intel/oneapi/setvars.sh --force`, set
`CMAKE_Fortran_COMPILER=/opt/intel/oneapi/compiler/2026.1/bin/ifx`,
`CMAKE_BUILD_TYPE=Release` and the flags above. The installed C11 consumer
source and exact compile/link commands are in m3-alpha-grid-c11.c/.log.
It checks number=3 and energy=A with two-sided spill using the installed header
and library, not the source-tree header.

Versioned m3-grid-*-{configure,build,ctest}.log are the observed results.
The separate 84-case source-grid convergence CSV was generated by root's
standalone g++ -std=c++17 -O3 executable, built from
fusion_alpha_spectrum.cpp, fusion_alpha_amplitudes.cpp,
fusion_nuclear_coulomb.cpp, fusion_products.cpp and
 tools/validate_alpha_grid.cpp with `-I include`. CMake also builds the same
diagnostic source as validate_alpha_grid; it is not part of default CTest.

The companion BALDUR Intel-r8 executable rebuilt and linked the current
library. Its log is in the host program records. No new host physics was
activated by this checkpoint, so that build is not claimed as kinetic
coupling or simulation validation.
